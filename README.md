# Alpha Innovator Trip Planner — Vercel Edition

This folder is a standard Next.js project prepared for Vercel.

## Run locally

1. Install Node.js 20 or newer.
2. Open this folder in VS Code.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open `http://localhost:3000`.

## Deploy with Vercel CLI

1. Run `npm install`.
2. Run `npm run build` to verify the project.
3. Install the CLI with `npm install -g vercel`.
4. Run `vercel login`.
5. Run `vercel --prod` from this folder.

## Deploy with GitHub

Upload this folder to a GitHub repository, import that repository from the Vercel dashboard, keep the detected framework as Next.js, and click Deploy.
